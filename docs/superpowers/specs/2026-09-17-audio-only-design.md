# 录音上传首版范围调整

用户于 2026-09-17 明确将首版收敛为“所有用户支持上传录音，暂不做飞书妙记”。这里的“所有用户”沿用产品现有边界：所有已登录用户，在候选人复盘和招聘评估两种工作台均可使用；未登录访问仍受保护。

## 用户流程

上传 MP3、M4A、WAV 或 OGG 录音 → 后台转写 → 用户检查逐字稿、确认说话人身份和文字 → 使用确认稿进行已有模式的面试分析。保留文件上传及粘贴文字入口；服务器未配置 ASR 时显示明确不可用提示。文件和时长限制为 500 MiB、60 分钟。

## 发布边界

不展示飞书妙记入口，不发起飞书 OAuth，不开放妙记链接导入或授权回调。已开发的飞书模块作为未启用的后续能力保留在代码中，本次不删除文件或历史；生产路由默认关闭，即便误放入飞书配置也不能开放。材料列表仅恢复音频任务。

现有音频任务、私有分块、短时供应商链接、用户隔离、24 小时清理、确认稿和报告关联均保持。真实语音识别仍依赖项目专用 ASR 配置；模拟测试与浏览器验收不能替代真实录音转写验收。生产只在 ASR 配置和真实联调完成后发布。

## 验收

两种模式都只显示录音入口；无飞书按钮、授权请求和链接表单。即使注入飞书配置，相关 HTTP 路径也返回 404 且不会调用飞书。音频权限、配额、恢复、取消、确认稿和两种分析模式回归通过。运行 `npm test`、`npm run build`、HTTP 与浏览器测试。
