## 可复现命令

```bash
npm test
npm run build
npx tsc --noEmit
```

浏览器脚本为 `scripts/verify-recording-ui.mjs`，只启动本地静态服务并拦截模拟 API，不导入生产 server、不访问真实账号、不调用付费模型。需要可用的 Playwright 与浏览器：

```bash
# PLAYWRIGHT_MODULE 可指向已有 Playwright 的 index.mjs；未设置时按正常包解析。
# 有系统 Chrome 时可以设置 BROWSER_CHANNEL=chrome。
node scripts/verify-recording-ui.mjs
```

`npx tsc --noEmit` 尚未通过，错误位于已有 `services/pdf/` 文件。对 `988c104` 基线与本分支分别运行，完整错误输出比对一致；没有使用 ignore/any 或修改检查规则来隐藏错误。
